===============================================================
PANDUAN MENGGANTI FOTO KARTU HARI GURU - BU DEWI ARNI, S.Pd.
===============================================================

Website ini sudah dilengkapi placeholder gambar SVG yang cantik dan anggun.
Jika Anda sudah siap memasukkan foto asli Ibu Dewi dan teman-teman sekelas,
Anda bisa langsung meletakkan foto asli Anda di folder ini:

1. Foto Profil Utama Bu Dewi:
   - File default saat ini: `foto-wali-kelas.svg`
   - Rekomendasi: Masukkan foto portrait Bu Dewi dengan nama `foto-wali-kelas.jpg`
     (dan di index.html ubah src="assets/images/foto-wali-kelas.svg" menjadi "assets/images/foto-wali-kelas.jpg").

2. Foto-foto Kenangan Kelas (Polaroid):
   - `foto-kenangan-1.svg` -> Momen belajar matematika
   - `foto-kenangan-2.svg` -> Foto bersama sekelas 11 RPL B
   - `foto-kenangan-3.svg` -> Canda tawa / momen ceria
   - `foto-kenangan-4.svg` -> Bimbingan / nasihat wali kelas
   - `foto-kenangan-5.svg` -> Momen coding / lab RPL
   - `foto-kenangan-6.svg` -> Momen Hari Guru / perayaan bersama

Tips:
- Format foto yang didukung: .jpg, .jpeg, .png, .webp
- Rasio foto terbaik: 1:1 (persegi) atau 4:5 (portrait)
